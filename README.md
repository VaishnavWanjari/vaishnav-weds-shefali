# Vaishnav & Shefali

Wedding invitation site. Static files only, no build step: Vercel serves this folder as it is.

- `index.html`: the whole site (scripts, styles, fonts and logo are inlined)
- `art/`: the scene paintings, `photos/`: the couple's photos, `music.mp3`: background music
- `og.jpg`: the preview image shown when the link is shared
